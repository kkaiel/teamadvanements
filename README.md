# TeamAdvancements

Paper 26.3 / Java 25용 Donut Teams 연동 플러그인.

## 빌드
1. GitHub 저장소에 이 프로젝트의 파일을 업로드합니다.
2. `libs/DonutTeams-2.0.2.jar` 파일이 반드시 포함되어 있어야 합니다.
3. Actions 탭에서 `Build TeamAdvancements` 실행을 기다립니다.
4. 완료된 실행의 Artifacts에서 `TeamAdvancements`를 내려받습니다.

## 설치
`TeamAdvancements.jar`를 서버의 `plugins` 폴더에 넣고 서버를 재시작합니다.
DonutTeams 플러그인이 먼저 설치되어 있어야 합니다.

팀별 완료 기록은 `plugins/TeamAdvancements/teams.yml`에 저장됩니다.
